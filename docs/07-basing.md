# 거점과 당일치기 — 판정 기준

## 문제

일자 개념이 "1일 1도시" 였다. 실제 여행은 하루에 1~N 도시다 — 낮에는
근교를 다녀오고 저녁은 묵는 도시에서 보낸다. 그 모양이 엔진에 없었다.

예전 기준은 두 줄이었다.

1. 담은 아이템이 0.75일 이상이면 그 도시에서 잔다.
2. 아니면 여정 순서에서 **바로 앞뒤**에 있는 숙박 도시로 붙인다.

세 가지가 틀렸다.

- **순서를 먼저 정하고 숙박을 나중에 정했다.** 순서는 '총 이동 시간 최소'
  로 풀리므로 마드리드 → 세고비아 → 톨레도 같은 한 줄이 나오고, 세고비아
  에서 톨레도로 가는 렌터카 2시간 26분 구간이 생겼다. 그렇게 가는 사람은
  없다. 둘 다 마드리드에서 다녀온다.
- **붙일 후보가 순서상 앞뒤뿐이었다.** 실제 거점이 두 칸 떨어져 있으면
  아무리 가까워도 붙일 수 없었다.
- **0.75일 문턱이 사실상 전부를 통과시켰다.** 소도시 기본 코스가 딱 1.0일
  이라 톨레도도 세고비아도 '잘 만한 곳' 으로 판정됐다.

데이터에는 사람이 적어 둔 `hub` 매핑(톨레도·세고비아 → 마드리드)이 46개
도시에 들어 있었는데, 엔진이 한 번도 쓰지 않았다.

## 지금 기준

순서를 정하기 **전에** 거점을 고른다.

### 1. 거점 점수 — 다섯 요소의 가중합

| 요소 | 가중 | 무엇을 재는가 |
|---|---:|---|
| 교통 허브성 `reach` | 0.30 | 편도 2시간 안에 닿는 여행 도시 비율 + 데이터의 `hub` 매핑 + `교통중심` 태그 |
| 저녁·밤 `evening` | 0.25 | nightlife·food 테마 밀도 + `나이트라이프`·`타파스`·`미식`·`대도시` 태그 |
| 숙박 적합성 `lodging` | 0.20 | 권장 숙박일 `nights[0]` + `isHub` − `당일치기` 태그 |
| 다음 목적지 접근성 `onward` | 0.15 | 다른 도시까지 이동 시간의 중앙값 + 입·출국 도시 가산 |
| 볼 것 분량 `volume` | 0.10 | 그 도시에 담은 아이템 일수 |

값은 `src/lib/basecity.ts` 의 `BASE_WEIGHTS` 한곳에 있다.

**숙박 적합성은 대리 지표다.** 앱에 호텔 데이터가 없다. 호텔 수를 아는
척하는 대신, 아는 것으로 대신한다 — 도시 데이터에 사람이 적어 둔 권장
숙박일과 거점 여부다. "여기서 자는 것이 보통인가" 에 대한 사람의 판단이라
호텔 수보다 오히려 목적에 가깝다. 다만 대리 지표라는 것은 숨기지 않는다.

### 2. 당일치기 흡수 한계 — 편도 120분 / 왕복 4시간

하루 활동 8시간 중 4시간이 이동이면 절반이다. 그보다 멀면 거기서 자는
편이 낫다. 여행자 커뮤니티에서 흔히 말하는 한계(편도 1시간 30분~2시간)의
위쪽을 잡았다.

**렌터카는 빼고 잰다.** 거점에 묵으면서 근교를 다녀오는 데 하루짜리 차를
빌리는 사람은 없다. 차를 넣으면 기다리지 않는다는 이유로 도시 쌍의
60.6% 에서 차가 1순위가 되어, 실제로는 타지 않을 수단으로 '가깝다' 는
판정이 나온다.

### 3. 무조건 거점이 되는 경우

- 혼자 **1.5일** 이상 볼 것이 있는 도시 (`MOVE_WORTH_DAYS`).
  숙소를 옮기는 데 체크아웃·짐·체크인으로 반나절이 든다. 하루치를 보자고
  그 값을 치르지는 않는다.
- 사용자가 4단계에서 '짐 옮기기' 로 지정한 도시. 점수와 무관하다.

### 4. 거점 선정 — 가중 집합 덮기(탐욕법)

점수가 높고 많이 품는 도시부터 채택한다. 도시가 열 몇 곳이라 정확히 풀
이유가 없고, 탐욕법이 사람의 직관과도 맞는다 — "제일 큰 데를 잡고 거기서
다녀온다".

덮이지 않고 남는 도시(편도 2시간 밖의 외딴 곳)는 짧게라도 거기서 잔다.

### 5. 순서는 거점끼리만

당일치기 도시는 거점 뒤에 붙여 화면에 보여 주되, 이동 구간(hop)은 만들지
않는다. 있지도 않은 소도시 간 구간이 생기지 않는 이유다.

### 6. 하루의 모양

당일치기 날은 **저녁 전에 거점으로 돌아온다**. 저녁·밤은 거점에서 보낸다.
소도시는 저녁 식당이 일찍 닫고 막차도 있기 때문이고, 실제로 이렇게들
다닌다. 그래서 하루가 '반나절 근교 + 반나절 거점' 으로 쪼개진다 — 3단계
일수 조절이 0.5일 단위인 이유다.

## 검증

`app/scripts/basing-check.mjs` 가 사람이 아는 사례로 못 박아 둔다.

| 조합 | 기대 |
|---|---|
| 마드리드 + 톨레도 + 세고비아 | 마드리드 거점, 둘 다 당일치기, 이동 구간 0 |
| 세비야 + 코르도바 + 카디스 | 코르도바 흡수(1시간 22분), **카디스는 스스로 숙박**(2시간 17분 — 한계 밖) |
| 바르셀로나 + 지로나 + 몬세라트 | 바르셀로나 거점 |
| 마드리드 + 바르셀로나 | 둘 다 거점 |
| 마드리드 + 세비야 + 그라나다 | 셋 다 거점 (서로 멀다) |
| 말라가 + 론다 + 네르하 | 말라가 거점 |

가중치나 한계를 바꾸면 이 표가 먼저 깨진다.
