# 계획을 손에 들고 옮기기

> 사용자 질문: *"현재 내용은 기기마다 연동이 안되는 구조야?"*

맞다. 그리고 **그것은 고장이 아니라 구조**다. 이 앱에는 서버도 계정도 없다.

```
브라우저 ──▶ localStorage: trip-planner.v1.<나라>
                (기기 · 브라우저 · 출처 단위)
```

바깥으로 나가는 요청은 데이터 파일 받기와 새 판 확인뿐이고, 계획은 어디로도
가지 않는다. 그래서 가입도 로그인도 없고, 계획이 남의 서버에 올라가지 않고,
비행기 안에서도 열린다. 대신 잃는 것이 기기 간 연동이다.

옮기는 길은 **파일 하나**다. 그런데 그 길에 구멍이 셋 있었다.

---

## ① 아무 데도 없던 안내

`계획 내보내기` · `가져오기` 단추 두 개가 발치에 덩그러니 있었다. 무엇에
쓰는 것인지 한 줄도 없어서, **쓰는 사람이 이 기능의 존재를 몰랐다.**
"기기마다 연동이 안 되는 구조냐" 는 질문이 그래서 나왔다.

기능이 있는데 아무도 못 찾으면 없는 것과 같다. 접힌 칸으로 묶고 제목을
`다른 기기로 옮기기 · 동행자와 나누기` 로 달았다. 안에는 왜 파일이어야
하는지(서버가 없다)와 어떻게 하는지를 적었다.

## ② 실패가 화면에 안 나왔다

```ts
catch (e) { setError((e as Error).message); }
```

`error` 는 **나라 데이터를 못 받았을 때만**(`error && !index`) 그려지는
자리였다. 앱이 떠 있는 동안의 가져오기 실패는 거기 적혀도 아무 데도
나타나지 않는다. 엉뚱한 파일을 고르면 **아무 일도 안 일어났다.**

이 저장소에서 가장 나쁜 실패가 그것이다. 결과 줄을 따로 두어 성공도
실패도 화면에 남긴다.

## ③ 다른 나라 계획을 그대로 받아들였다

계획은 도시 slug 로 이루어져 있고, slug 는 나라 안에서만 뜻이 있다.
그런데 `importState` 는 나라를 보지 않았다.

스페인 계획을 일본 페이지에서 열면

- 없는 도시를 가리키는 계획이 되고,
- 저장은 **지금 페이지의 열쇠**(`trip-planner.v1.japan`)로 들어가
  두 나라가 한 서랍에서 섞인다.

나라마다 저장 열쇠를 쪼갠 이유가 바로 그것이었는데, 가져오기 길만 그 규칙을
비껴가고 있었다. 이제 나라가 다르면 받지 않고, 어느 나라 파일인지와 어디로
가야 하는지를 사람 말로 알린다.

## ④ 덮어쓰기를 묻지 않았다

가져오기는 지금 계획을 통째로 갈아엎는다. 2천 개에서 골라 둔 것이 한 번의
잘못 누름으로 사라지면 안 된다. 묻고, 남기려면 먼저 내보내라고 알린다.

---

## 파일 이름은 ASCII 여야 한다

이미 아는 함정인데 다시 확인했다. `<a download>` 에 한글이 들어가면 브라우저는
이름을 통째로 버린다. 되돌려 시험해 보니 실제로 이렇게 나왔다.

```
✗ 내보낸 파일 이름이 ASCII 다 — download
```

`.json` 확장자까지 사라져서 가져오기가 파일을 못 알아본다. 내 지도 KML 에서
한 번 겪고 적어 둔 것이 여기서도 그대로 통했다.

---

## 곁다리로 드러난 검사의 약점

발치에 칸을 하나 더 붙였더니 **앱은 멀쩡한데 검사가 실패했다.**

```
✗ 맨 아래 카드가 막대에 가리지 않는다
```

`맨 아래로 스크롤 → 마지막 도시 카드가 눌리는가` 로 재고 있었는데, 그것은
**마지막 카드가 페이지의 맨 아래에 있다** 는 우연에 기댄 방식이었다. 목록
아래에 무언가가 붙자 카드가 화면 위(`y = -139`)로 밀려 나갔다.

카드를 화면 안으로 끌어오는 것(`scrollIntoViewIfNeeded`)으로 고쳐 봤더니
이번엔 브라우저가 막대를 피해 스크롤해서 **막대를 200px 로 키워도 안 걸렸다.**
검사를 고치다 더 무디게 만든 것이다.

재려던 것은 '본문이 막대 아래로 들어가지 않는가' 였으므로 그것을 그대로 잰다.

```js
window.scrollTo(0, document.body.scrollHeight);
bar.top - main.bottom   // 음수면 겹친 것
```

정상 37px · 막대를 200px 로 키우면 −88px. 발치에 무엇을 더 붙이든 흔들리지
않고, 진짜 겹침만 잡는다.
