# 섬 단위 여행과 묶음 제안

## 1. 섬은 자치주가 아니라 섬 하나가 여행 단위다

### 무엇이 틀렸나

`region` 이 자치주라 **테네리페와 그란카나리아가 똑같이 '카나리아'** 였다.
`crossesSea()` 가 자치주를 비교했으므로 두 섬 사이가 육지로 판정됐다.

```
산타크루스데테네리페 → 라스팔마스
   렌터카 2시간 3분 | 일반열차 2시간 9분 | 시외버스 2시간 15분
```

대서양 60km 를 렌터카로 건너라는 안내였다. 게다가 **그란카나리아에는
철도가 없는데** 거리만 보고 '일반열차' 를 지어냈다.

그리고 아이템 수집이 도시 단위였다. 마요르카는 팔마·소예르·포옌사만
모았는데, 그 섬에서 가장 많이 찾는 곳들은 다른 자치시에 있어 **데이터에
아예 없었다** — 발데모사(쇼팽의 수도원), 데이아, 드라크 동굴,
에스 트렌크, 세라 데 트라문타나.

### 어떻게 고쳤나

**섬 정체성** (`pipeline/registry/spain-character.mjs` 의 `ISLANDS`)

| 섬 | 도시 | 철도 |
|---|---|---|
| 마요르카 | 팔마 · 소예르 · 포옌사 | 있음 (팔마~소예르 목재 열차) |
| 테네리페 | 산타크루스 · 라라구나 · 푸에르토데라크루스 · 라오로타바 | 있음 (트램) |
| 그란카나리아 | 라스팔마스 · 마스팔로마스 | **없음** |

- `crossesSea` 가 자치주가 아니라 **섬 id** 를 본다.
- 섬에 철도가 있다고 데이터가 말하지 않으면 열차를 만들지 않는다. 모르면
  없다고 본다 — 없는 열차를 지어내는 것보다 있는 열차를 놓치는 편이 낫다.
- 가까운 섬끼리(150km 이내)는 **고속 페리**를 넣었다. 예전에는 '배는 반나절
  걸린다' 며 비행기만 내놓았는데, 60km 구간에 4시간짜리 공항 왕복을 하라는
  안내가 됐다.

```
산타크루스데테네리페 → 라스팔마스
   ⛴️ 고속 페리 2시간 36분 | ✈️ 국내선 항공 4시간 2분     (육로 없음)
라스팔마스 → 마스팔로마스
   🚌 버스 1시간 27분 | 🚗 렌터카 1시간 31분              (열차 없음)
```

**1단계에서 섬마다 한 칸** — '섬 (발레아레스·카나리아)' 한 칸에 아홉
도시를 섞어 두면, 대서양을 사이에 둔 두 섬이 나란히 있는 것이 보이지
않는다. 칸마다 섬 안 교통 안내가 붙는다.

**섬 전체가 후보** (`app/src/lib/island.ts`) — 섬 도시를 하나라도 고르면
그 섬의 아이템을 전부 불러오고, 고르지 않은 도시의 것은 **가장 가까운
고른 도시로 옮겨 붙인다.** 섬에서는 렌터카로 30~40분이면 반대편이고
실제로 팔마에 묵으며 섬 전체를 돈다. 옮겨 온 것은 `🚗 소예르 방면` 처럼
표시해, 도심 한복판과 같은 얼굴로 보이지 않게 한다.

```
팔마만 골라도 → 후보 117곳 (그중 섬 안 다른 동네 70곳) · 자연·해변 31곳
```

**빠진 명소를 채웠다** (`pipeline/island-extras.mjs`, 10곳). 좌표와
Wikidata id 는 지어내지 않고 받아서 검증했다
(`node pipeline/verify-extras.mjs`). 마스카(Masca)는 Wikidata 항목을
확정하지 못해 넣지 않았다 — 확인 못 한 좌표를 넣느니 빠뜨리는 편이 낫다.

## 2. 묶음 제안

낱개로만 보여 주면, 한 장의 표로 묶이거나 같은 건축가의 연작이라 함께
봐야 뜻이 통하는 것들이 흩어진다. 구엘 공원만 담고 구엘 저택을 빼면
가우디가 한 후원자를 위해 한 일을 반쪽만 보게 된다.

**지어내지 않는다.** 두 가지만 넣었다.

- **실제로 파는 통합권** — 데이터의 설명이 이미 그렇게 적고 있는 것들
  ("히브랄파로 성과 묶은 통합권이 쌉니다", "보통 알함브라 통합권에
  포함됩니다", "카우 페라트와 운영 시간이 같습니다").
- **한 자리에 붙어 있어 나눌 이유가 없는 것** — 세비야 대성당과 히랄다는
  같은 표로 들어가는 한 건물이다.

| 묶음 | 곳 | 요금 |
|---|---|---|
| 프라도 · 레이나 소피아 · 티센 | 3 | 통합권 €32 vs 낱장 €40 |
| 알카사바 · 히브랄파로 · 로마 극장 | 3 | 통합권 €6 vs 낱장 €10 |
| 구엘 공원 · 구엘 저택 | 2 | 낱장 €22 |
| 카사 바트요 · 카사 밀라 | 2 | 낱장 €58 |
| 알함브라 · 헤네랄리페 | 2 | 통합권 포함 |
| 대성당 · 왕실 예배당 (그라나다) | 2 | 낱장 €10 |
| 세비야 대성당 · 히랄다 | 2 | 같은 표 |
| 톨레도 유대인 지구 (시나고그 둘 + 수도원) | 3 | Pulsera Turística |
| 카우 페라트 · 마리셀 (시체스) | 2 | 통합권 |

값은 바뀐다. 그래서 금액은 '대략' 으로만 적고 확인은 공식 홈페이지로
넘긴다 — 다른 요금 정보와 같은 원칙이다. 데이터에서 id 가 사라지면 그
묶음은 조용히 빠지고 화면이 깨지지 않는다.

## 검증

`app/scripts/island-check.mjs` — 섬 정체성, 육로로 바다를 건너지 않는지,
없는 철도를 만들지 않는지, 섬 전체가 후보가 되는지, 본토가 영향을 받지
않는지, 묶음 9개가 전부 조립되는지.

`pipeline/verify-extras.mjs` — 추가한 10곳의 좌표를 Wikidata 와 다시 대조.
